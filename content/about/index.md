我是 MicroWearld。这个博客是深夜编辑部：冷调、衬线、代码雨，写半技术半随笔的东西——教程、复盘，以及和 AI 一起干活时冒出来的想法。

## 我在做什么

日常实验是「人和 agent 协作写代码」。最近的主线是和 DeepSeek Harness（dsh）、Hermes 这类 agent 长期配合，一起把 A2A 协议接进插件体系——让 agent 之间也能互相调用。这条线从模糊的需求开始，跨了几周才长出两个插件，过程都记在[与 AI 协作](/series/与-ai-协作/)系列里。

博客之外还在折腾的：

- Windows 下的终端与自托管工具链：scoop、Starship、代理规则、本地服务，把常用环境磨到顺手

## 这个博客写什么

文章按三个分类归档，对应三种阅读预期：

- **学习记录** —— 把踩过的坑写成教程。照着能走通，是这类文章的验收标准
- **项目工作** —— 攻一个真实问题的全程复盘。过程比结论重要
- **个人随笔** —— 感想与杂记。没有交付物，只有想清楚的过程

每篇文章的 front matter 带一个 `mode` 字段（tutorial / note / story），与分类对应，相当于阅读契约：打开之前你就知道这是「可照做的」还是「陪我经历的」。

系列则是另一条轴：跨分类的叙事线。[与 AI 协作](/series/与-ai-协作/)目前是唯一一条——同一批事件，分别以教程、复盘、随笔三种形态出现过。

## 写作原则

- 技术文先给一句话模型，再给细节
- 事实锚定可查证的数据，不复述二手结论
- 中文优先，术语保留原文便于检索
